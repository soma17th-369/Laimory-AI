# worklog 템플릿

작업과 검증을 끝낸 뒤 아래 골격으로 기록한다.

```markdown
---
date: YYYY-MM-DD
agent: codex 또는 claude
model:
branch:
status: done
plan: ../plans/YYYY-MM-DD-작업-슬러그.md
issue:
related: []
---

# 작업 제목

## 배경

작업을 시작한 이유와 승인된 목표를 요약한다.

## 한 일

- 실제로 변경한 내용

## 판단

- 구현 중 내린 중요한 결정과 선택하지 않은 대안

## 검증

- 실행한 명령과 결과

## 바꾼 파일

- 파일과 변경 목적

## 남은 것

- 후속 작업이나 미해결 사항
```

계획과 실제 결과가 달라졌다면 차이와 이유를 숨기지 말고 `판단`에 기록한다. 비밀값, 토큰, 원본 사용자 데이터는 남기지 않는다.
