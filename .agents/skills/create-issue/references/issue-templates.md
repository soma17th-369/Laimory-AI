# 이슈 본문 템플릿

이슈 **본문(`--body-file`)**의 골격이다. 결정된 Type에 대응하는 템플릿이 있으면 그걸 채워 쓰고,
없으면 SKILL.md의 일반 골격(배경/상세/완료조건)을 쓴다.

| Type | 사용 템플릿 |
|---|---|
| **Bug** | Bug 템플릿 |
| **Feature** | Feature 템플릿 |
| **Task** (리팩터링 성격) | Refactor 템플릿 |
| **Task** (그 외) · **Epic** | 일반 골격 (SKILL.md 1단계 참고) |

채울 때는 주석(`<!-- ... -->`)을 실제 내용으로 바꾸되, 알 수 없는 항목은 빈칸으로 남겨 작성자가
채우게 둔다. 빈 섹션을 통째로 지우지 말 것 — 팀이 항상 같은 형식을 보도록 유지한다.

---

## Bug

```markdown
## 🛠️ 발견된 버그 기능
<!--어떤 부분에서 버그가 나오는지 기입합니다.-->

## 🌎 발견된 환경
- 서버 (dev, prod):
- 발생 API:
- 에러 코드:

## 💻 에러 로그
<!--에러 로그를 기입합니다.-->

## 💡 해결방안
<!--해당 에러를 어떻게 해결할 것인지, 어떻게 임시적 처리를 진행해야 하는지 상세히 기입합니다.-->
```
